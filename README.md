
# Real-Time Interactive CPU Scheduling Simulator

A modern CPU Scheduling Simulator developed using Python and CustomTkinter that visualizes different scheduling algorithms in real time with animated Gantt charts, live metrics, and interactive process management.

---

## Features

- Real-time CPU scheduling simulation
- Animated Gantt chart
- Live process table
- Ready queue visualization
- Multiple scheduling algorithms
- Dynamic process add/edit/delete
- Performance metrics calculation
- Adaptive scheduling feedback
- Export reports (PDF, PNG, Excel)

---

## Algorithms Implemented

- FCFS
- SJF Non-Preemptive
- SRTF
- Priority Non-Preemptive
- Priority Preemptive
- Round Robin
- MLFQ

---

## Technologies Used

- Python
- CustomTkinter
- Tkinter
